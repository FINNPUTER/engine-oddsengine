# 2.30.0 OddsEngine AI: full catalog, holder fees, fixed top up

## What is new
- All paid OpenRouter models are available. The curated ones are marked `picked`, models from the
  last 21 days are marked `new`. The page has categories: Picked for you, New, Best for code, Writing,
  Deep thinking, Sees images, Creates images, Long documents, Fast and cheap, Web search, All.
- Holder fee tiers. The fee depends on the $ODDS a user holds (connected wallet plus linked Torch
  wallets), checked on each request and remembered for 5 minutes. Never below the floor.
- Top up with a fixed dollar amount: `POST /v1/ai/quote {"usd": 10}` holds the price for 10 minutes.
  A matching transfer (97 to 150 % of the quoted $ODDS, within 20 minutes) is credited at that price.
- Chat images: `GET /v1/chat/img/{id}?key=...&dl=1` downloads the file.
- `/v1/engine/me` returns `ai.holder` (held, markup, next tier, all tiers).

- Every OpenRouter model: paid ones, free ones (20 messages a day per wallet, no balance needed,
  `AI_FREE_PER_DAY`), batch versions, `~latest` names and routers like `openrouter/fusion`.
  Only `openrouter/auto` (we have `oddsengine/auto`) and audio-output models are left out.
- Compare in the chat: one message to 2 or 3 models at once, answers side by side (frontend,
  uses `/v1/ai/chat`, each answer billed normally).
- Operator card: "OpenRouter left" shows n/a instead of $0.00 when OpenRouter does not tell us.

- Operator card: top 30 users (spent, topped up, left, requests, last seen), users in the last
  7 days, free messages in the last 24 hours.
- Maker logos on model cards and in the model picker.

- Telegram alert to the operator when 70 % and again 90 % of the OpenRouter key limit or
  credit is used, and when customers hold more credit than OpenRouter has left. Checked every
  10 minutes, each level once until you top up. Test button in the operator card.

## Railway variables (service web), all optional
- `AI_MARKUP`        base fee, default 0.095. If you set 0.08 earlier, delete it or set 0.095.
- `AI_HOLDER_TIERS`  default `250000:0.09,1000000:0.085,3000000:0.08,10000000:0.075`
- `AI_MARKUP_FLOOR`  default 0.075. No tier goes below this, so no request runs at a loss.
- `AI_MODELS`        default every model. `curated` = only the picked list.
- `AI_ALERT_AT`      default 0.7. Uses TELEGRAM_BOT_TOKEN and TELEGRAM_PRIVATE_CHAT_ID (already set),
  or `AI_ALERT_CHAT_ID` for a different chat.
- `AI_FREE_PER_DAY`  default 20 free messages per wallet and day.

Nothing else changes. No new service, no new database, tables stay the same.
