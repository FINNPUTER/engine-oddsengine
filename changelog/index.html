2026-11-08v2.80

Locker page: extra safety checks

  • The page only talks to the one ODDS Locker contract it was built for. If the server ever named another contract, every button locks and a warning shows.
  • NFT positions (for example Uniswap V3 LP) are blocked before you approve anything: they could not be withdrawn again.
  • Locking for another wallet needs a second confirmation, with a clear warning for contracts and exchange deposit addresses.
  • Independent review of the contract: only the lock owner can withdraw, nothing unlocks early, and the admin can only change fees and the treasury.
