# 2.29.0 OddsEngine AI

Every model through one key, paid in $ODDS. Runs on the web service, no new Railway service.

## What is new
- `ai.py`, `ai_api.py`: OpenRouter proxy, API keys (`oe_live_...`, stored as SHA-256 only), balances in USD,
  deposit detection from $ODDS transfer logs on Robinhood Chain, usage log, operator numbers.
- OpenAI compatible: `GET /v1/models`, `POST /v1/chat/completions` (stream and non-stream).
- engine.oddsengine.live: login with a wallet signature, balance, top up, keys, playground, model gallery,
  compare, operator card. Torch wallets are linked by sending 1 $ODDS (same as the holder link since 2.23).

## Money
- Price = OpenRouter cost + `AI_MARKUP` (0.08). Shown inside every price on the page.
- Before every request the maximum possible cost is reserved, afterwards it is settled to the real cost
  OpenRouter reports. Nobody can overspend with parallel requests.
- A deposit is credited in USD at the $ODDS price at the moment it is seen. Senders must be the connected
  wallet or a linked wallet. Everything else shows up as "Deposits nobody claimed yet" in the operator card
  and is credited automatically once that wallet connects or gets linked.
- Burn: not in this version, comes as its own announcement.

## Railway variables (service web)
- `OPENROUTER_API_KEY`  required
- `AI_DEPOSIT_ADDRESS`  optional, default 0xaA0C5bA57c4Bd19b232D63828835267B36136907
- `AI_MARKUP`           optional, default 0.08
- `AI_MODELS`           optional: empty = curated list, `all` = every paid model, or a comma list
- `AI_RATE_PER_MIN`     optional, default 60 requests per minute per key

## Switch
`ai` on admin.html opens the AI tab, the playground and the public API. Off: teaser, keys stop working.
Admins can test everything before (admin key in the browser).

# 2.29.1 Chat

A full chat on engine.oddsengine.live, like ChatGPT: tab "Chat".
- `chat.py`: chats per wallet in Postgres (`ai_chats`, `ai_msgs`, `ai_images`). Titles, messages and images are
  encrypted (AES-GCM, key derived from `AUTH_SECRET`). Nobody reads them in the database, also not the operator.
- Users can delete one chat or all chats. Max 200 chats per wallet, the oldest goes when full.
- Images: attach up to 4 per message (models marked "sees images"), or pick an image model to create pictures.
  Stored images are deleted after `AI_IMAGE_DAYS` (default 30).
- Every answer shows its exact cost and is paid from the same balance as the API.
- Simple price overview in the API tab: Cheap, Standard, Premium, Images with "about N for $1".

Optional variable (service web): `AI_IMAGE_DAYS` default 30.
Tables are created on start, nothing to do in Railway.
